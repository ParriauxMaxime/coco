Links Paseo to cocopilot, the local workbench for PR stacks and code review (served at `http://127.0.0.1:8777` by default).

A workspace panel shows the cocopilot work matching the workspace's branch, its PR, review comment counts, and the review fixes and stack fixes that touch the workspace, each with buttons to open its Paseo agent or its cocopilot run tab. Review, PR, plan and run tabs open in a workspace browser tab on desktop or in the system browser elsewhere. A header button and a composer pill on linked workspaces show the PR state or the running fix. Command Center items open the panel, the current PR's review, or cocopilot itself.

Agents cocopilot launches carry labels (`source=cocopilot`, `kind`, `run`, `work`, `comments`, `pr`). Each such agent gets a composer pill naming its run and opening its cocopilot tab, and a run card at the top of its timeline when its turn starts. When cocopilot is asked to launch on behalf of an agent, it sets Paseo's parent label, so the run also shows in that agent's subagents and its card lands in that agent's timeline too.

An agent started by hand (no `source` label) in the workspace of a PR row of a work is linked to that PR when it is created; cocopilot lists it on the PR's agent tab and on its Agents page. Its composer gets an "add work brief" pill that, on press, sends the PR's work brief from cocopilot as a message to that agent. Nothing is sent without that press. An archived agent is unlinked.

When an agent turn ends, the daemon tells cocopilot, which settles the review fix or stack fix handed to that agent and records fixed or declined comments right away instead of on its next poll. The run cards then switch to done or failed with the fixed and declined counts. The hook also sends the agent's cwd: when its branch is a row of a work (a PR, or a local branch not pushed yet), cocopilot re-reads every row's head (GitHub for PRs, the local branch tip otherwise) and re-anchors that row's review comments, so a commit, restack or push made in the turn shows in the review tabs.

Setup: run the cocopilot server on the daemon machine (`npm start` in the cocopilot folder), then `paseo plugin install <absolute path to cocopilot>/paseo-plugin`. Settings → Plugins → cocopilot sets its URL, `http://127.0.0.1:8777` by default. Nothing leaves the machine; the plugin only talks to that URL.
